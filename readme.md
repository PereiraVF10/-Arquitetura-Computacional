# Arquitetura Computacional Cruzadinha

## 📖 Sobre o Jogo
Jogo de cruzadinha interativo desenvolvido em HTML, CSS e JavaScript puros para fixação dos conceitos fundamentais de Tópicos de Arquitetura Computacional (Sprint 3) da SPTECH School.

---

## 🕹️ Como Jogar
1. **Preenchimento:** Digite as letras diretamente nas células do tabuleiro numeradas conforme as pistas. Utilize o teclado (setas e backspace) para navegar facilmente.
2. **Validação:** Clique no botão **"Conferir Respostas"**. O sistema valida cada quadrado individualmente destacando em **verde** os acertos e em **vermelho** os erros.
3. **Travamento de Acertos:** As letras das palavras que forem acertadas são travadas automaticamente, impedindo alterações posteriores.
4. **Respostas nas Pistas:** As respostas completas são reveladas em verde junto às pistas na lateral após o acerto e permanecem fixas até o reset.
5. **Placar:** Acompanhe o progresso em tempo real através do contador de palavras corretas localizado no topo.

## 📝 Lista Completa de Palavras e Pistas

### Horizontais
* **1. CPU:** Cérebro principal responsável por coordenar e executar instruções.
* **5. RAM:** Memória de acesso aleatório principal e volátil.
* **6. ROM:** Memória apenas de leitura para inicialização do sistema.
* **7. EEPROM:** Memória flash programável eletricamente e apagável.
* **8. Flash:** Tecnologia de armazenamento baseada em estado sólido rápida.
* **9. cache:** Memória de altíssima velocidade próxima aos núcleos.
* **11. DMA:** Permite transferência direta de dados sem uso intensivo da CPU.
* **13. data bus:** Barramento responsável pelo transporte real dos dados.
* **14. microcontrolador:** Sistema computacional completo integrado em um único chip.
* **15. dual core:** Processador equipado com dois núcleos físicos independentes.
* **16. quad core:** Processador que possui quatro núcleos de processamento simultâneo.

### Verticais
* **2. ULA:** Parte que faz contas e operações lógicas.
* **3. UC (Unidade de Controle):** Gerencia e direciona as operações do sistema.
* **4. registradores:** Pequenos espaços de armazenamento ultrarrápidos internos.
* **10. memória de massa:** Dispositivos de armazenamento não volátil de grande capacidade.
* **12. address bus:** Barramento que define as posições de memória acessadas.
